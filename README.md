# AZ Commerce – E-Commerce Website

AZ Commerce is a complete, modern, and responsive e-commerce web application built as a student portfolio project. It features a React.js frontend built with Vite and vanilla CSS, a Django REST Framework backend with JWT authentication, and a MySQL database integration.

---

## 🛠️ Technology Stack

### Frontend
- **React.js & Vite**: Fast development server and builds.
- **JavaScript & React Router DOM**: Client-side routing.
- **Axios**: Network client for talking to Django APIs.
- **Lucide React**: Clean and modern vector icon set.
- **CSS3 (Vanilla)**: Fully custom responsive grid and card design system.

### Backend & Database
- **Python & Django**: Powerful MVC framework.
- **Django REST Framework (DRF)**: REST API generation.
- **Simple JWT**: JSON Web Token authorization standard.
- **MySQL**: Persistent relational database (with automatic SQLite fallback for simple demo runs).

## ⚙️ Installation & Running Guide

### Step 1: Pre-requisites
Ensure you have the following installed on your machine:
- Python (v3.9 or higher)
- Node.js (v16 or higher)
- MySQL Server (Optional - falls back to SQLite if not running)

---

### Step 2: Backend Setup (Django)

1. **Navigate to the backend folder**:
   ```bash
   cd backend
   ```

2. **Create a Python Virtual Environment**:
   ```bash
   python -m venv venv
   ```

3. **Activate the Virtual Environment**:
   - **Windows (PowerShell)**:
     ```powershell
     .\venv\Scripts\Activate.ps1
     ```
   - **Windows (CMD)**:
     ```cmd
     .\venv\Scripts\activate.bat
     ```
   - **macOS / Linux**:
     ```bash
     source venv/bin/activate
     ```

4. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

5. **Configure environment variables (`.env`)**:
   Open `backend/.env` and update the parameters matching your local MySQL credentials:
   ```env
   SECRET_KEY=django-insecure-az-commerce-secret-key-student-project-2026
   DEBUG=True
   DB_NAME=az_commerce
   DB_USER=root
   DB_PASSWORD=root
   DB_HOST=127.0.0.1
   DB_PORT=3306
   ```
   *Note: If `mysqlclient` is not installed or MySQL is unavailable, Django will log a warning and fall back automatically to a SQLite database (`db.sqlite3`) for running in local testing mode immediately.*

6. **Create the Database** (Only if using MySQL):
   Access your MySQL CLI and create the schema:
   ```sql
   CREATE DATABASE az_commerce;
   ```

7. **Run Database Migrations**:
   ```bash
   python manage.py migrate
   ```

8. **Seed the database with sample products & users**:
   AZ Commerce contains a built-in database seeder that automatically configures categories, products, ratings, reviews, and preset authentication users.
   ```bash
   python manage.py seed_db
   ```

9. **Start the Django Development Server**:
   ```bash
   python manage.py runserver
   ```
   The backend API will be live at `http://127.0.0.1:8000/`.

---

### Step 3: Frontend Setup (Vite + React)

1. **Navigate to the frontend folder**:
   ```bash
   cd ../frontend
   ```

2. **Install node dependencies**:
   ```bash
   npm install
   ```

3. **Launch the development server**:
   ```bash
   npm run dev
   ```
   The React frontend will be live at `http://localhost:3000/`.
